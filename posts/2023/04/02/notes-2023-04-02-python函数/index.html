2. 自定义函数

2.1 无参数无返回值

  • 定义函数
    • def + 函数名():
    • 函数体
  • 调用函数
    • 函数名():

2.2 有参数无返回值

  • 定义函数
    • def + 函数名(形参):
    • 函数体
  • 调用函数
    • 函数名(实参):
  • 传入参数
    • 形参
      • 形式上的参数
      • 定义函数时的临时变量
    • 实参
      • 实际调用时传入的参数

2.3 有参有返回值

  • 定义函数
    • def + 函数名(形参):
    • 函数体
    • return + 内容 （不写内容默认返回None）
  • 调用函数
    • 函数名(实参):
  • 函数都是有返回值的，每个函数都会在最后一行默认加return None
  • return可以返回一个内容，最终会作为函数运行的结果
  • return后的代码都不会执行，可以中断函数执行
