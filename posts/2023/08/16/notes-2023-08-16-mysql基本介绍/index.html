MySQL：基本介绍

MySQL的基本概念

#MySQL

1. SQL语句的基本介绍

​ SQL全称是结构化查询语言(Structured Query Language)，是关系型数据库管理系统都需要遵循的规范，是操作关系型数据库的语言，只要是关系型数据库，都支持SQL。

​ 虽然所有的关系型数据库都支持SQL，但是不同的关系型数据库都会有一些特殊的东西(特有的函数或语法)。

​ 普通话：各数据库厂商都遵循的ISO标准。

​ 方言：数据库特有的关键字。

​ SQL语句的主要作用就是对数据库中的数据进行相应的管理操作（增、删、改、查）。

  • 数据库的增、删、改、查
  • 数据表的增、删、改、查
  • 表记录的增、删、改、查
    ……

2. SQL语句分类

SQL分类：

  • 数据定义语言：简称DDL(Data Definition Language)，用来定义数据库对象：数据库，表，列等。关键字：create，alter，drop等
    • 作用： 对数据库中的 库 和 表 进行定义 （创建数据库、删除数据库、查看数据库、创建表、删除表、修改表、查询表）
    • 注意： 数据库定义语言，不涉及到对表数据处理
  • 数据操作语言：简称DML(Data Manipulation Language)，用来对数据库中表的记录进行更新。关键字：insert，delete，update等
    • 作用： 对 数据库中表数据进行操作（添加数据、删除数据、修改数据）
  • 数据控制语言：简称DCL(Data Control Language)，用来定义数据库的访问权限和安全级别，及创建用户。（DBA工程师）
    • 作用： 对数据库这个软件进行管理的语言。 比如 设置用户名、设置密码、设置不同用户可以访问那些库或者那些表
  • 数据查询语言：简称DQL(Data Query Language)，用来查询数据库中表的记录。关键字：select，from，where等
    • 作用： 对数据库中表数据进行查询操作

3. SQL通用语法

通用语法：

  • 1- SQL语句可以单行或多行书写，以英文分号结尾
  • 2- MySQL数据库的SQL语句不区分大小写，关键字建议使用大写
    • 例如：SELECT * FROM user。
  • 3- 同样可以使用/* 注释内容 */、– 、# 的方式完成注释
    • DataGrip快速注释/取消注释的快捷键：ctrl + /
  • 4- 可使用空格和缩进来增强语句的可读性
    • DataGrip软件sql格式化快捷键： ctrl + alt + l
