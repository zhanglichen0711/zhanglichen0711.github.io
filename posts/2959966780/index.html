从机器学习术语到反向传播：深度学习笔记

线性回归、树模型和 KNN 解决的是「怎么学」；张量、反向传播和优化器解决的是「深层网络怎么更新」。

#深度学习 #NLP
目录

课堂顺序通常是：人工智能 / 机器学习 / 深度学习三个概念 → 线性回归与 KNN → 决策树 → PyTorch 张量 → 建网、训练、反向传播 → 正则化。做应用不必把每个公式重推一遍，但要知道自己调用的 BERT、YOLO 大致在哪一层。

三个词不要混

  • 人工智能：目标是让机器完成需要智能的任务。
  • 机器学习：用数据拟合可泛化的规则，而不是把规则写死。
  • 深度学习：用多层可微模块自动学表示，数据量和算力是前提。

常用术语里，先记住：样本、特征、标签、训练集 / 验证集 / 测试集、过拟合、欠拟合。后面所有「准确率 96%」如果没说清这三套数据如何划分，数字就不可比。

传统模型仍有位置

线性回归给了正规方程和梯度下降两条路，核心是「损失对参数可导就能迭代」。KNN 没有显式训练过程，贵在理解和距离；超参数 k、是否标准化、网格搜索，是后面调 BERT 学习率之前就该有的实验习惯。

决策树和随机森林在表格数据、小样本、要可解释性时仍然好用。文本层级分类可以先拿森林和 FastText 打基线，再决定要不要上 BERT。不是所有任务第一天就必须是 Transformer。

张量和一层网络

PyTorch 里，文本、图像最后都变成张量。nn.Linear 就是一层仿射变换。初始化不是细节：全零会让对称神经元学到同一套更新；Kaiming / Xavier 是为了让信号在深度里不至于一开始就消失或爆炸。

建模型的固定动作：

  1. 继承 nn.Module
  2. 在 __init__ 里声明层
  3. 在 forward 里写数据怎么流
  4. 选损失、选优化器、写训练循环

反向传播只记一条链

前向算出损失，反向沿计算图把梯度传回每个权重。更新后再把梯度清零，否则会把上一步的梯度累加上去。

优化器是在「纯 SGD 容易卡在平坦区域或鞍点」之后出现的：

  • Momentum：带着历史速度走
  • Adagrad / RMSProp：按参数自己的历史梯度调整步长
  • Adam：两者思路的常用组合

学习率比换一个更花哨的网络结构更常成为成败原因。

正则化是上线前的刹车

Dropout 让网络不能依赖某个神经元。BatchNorm 让各层输入分布不至于漂移。对应到应用侧，还有更土的刹车：早停、标签清洗、把低置信度样本交给规则或 LLM 兜底。

接到现在的工作方式

分类任务可以先用 Scikit-learn 和 FastText 建基线，再用 BERT 微调。检测任务用 YOLO 时，先问数据集是不是和业务同分布。深度模型给出的是概率而不是业务结论；和 RAG、规则、人工复核接在一起，才是应用。
