NLP 笔记：从分词、词向量到 Transformer

预处理决定模型吃进什么；RNN 解决序列；Attention 和 Transformer 解决长距离依赖。BERT 和 GPT 是同一骨架的两种用法。

#NLP #Transformer #BERT
目录

NLP 可以看成一条越来越短的流水线：文本先被切成模型能吃的单元，再变成向量，再进序列模型。2017 年的 Transformer 把「序列计算」从逐步递推改成了可并行的注意力。

预处理不是杂务

目标只有一个：得到稳定的 DataLoader。中文没有空格，分词会改变后续全部统计。jieba 的精确 / 全模式 / 搜索引擎模式，对应的是「分析一句」还是「多召回一些片段」。领域词必须进自定义词典，否则「混凝土强度」会被切碎。

和分词并列的还有：

  • NER：人名、地名、机构、时间、标准号。规范问答里，标准号往往比形容词更重要。
  • 词性：不是所有任务都要，但对规则过滤有用。
  • 表示：one-hot 只适合演示；词向量把词放到连续空间里，文本张量才是网络输入。

数据侧常见动作：看长度分布、去高频停用词、处理类别不平衡、用简单替换做一点增强。增强解决的是稀疏，不是标注错误。

RNN 家族解决了什么

RNN 把前一时刻的隐状态传给下一时刻，能看序列，但长程依赖和并行都不理想。LSTM / GRU 用门控减轻遗忘和梯度问题。人名分类、短句情感，这一代模型够用；长规范、长标书，代价会明显上去。

Attention 在改变计算方式

注意力的直觉：当前这个位置，该看序列里的哪些位置、看多深。Q / K / V 把「问」「被检索」「被取出的内容」分开。Self-Attention 让每个词看到整句，而不必沿时间一步步走。

Transformer 为什么成为默认骨架

编码器、解码器、多头注意力、前馈层、残差和 LayerNorm，组成一块可堆叠的砖。优势是并行和长程依赖；代价是对数据和算力更敏感，位置信息要额外编码。

同一块砖，后来走出两条路：

  • BERT：双向编码器，适合理解、分类、抽取。
  • GPT：自回归解码器，适合生成。

HuggingFace 把「加载预训练 + 换头 + 微调」变成常规动作。迁移学习通常有两种：冻住前面只训头，或整网小学习率微调。领域数据少时，前者更稳。

FastText 不要丢

FastText 能做有监督分类，也能训词向量。层级标签、短文本、要速度快的基线，它经常比一上来微调 BERT 更诚实。对比完再上大模型，评测集才有参照。

接到 RAG / Agent 时

分词和 NER 会进入切分和元数据。词向量和 embedding 模型是检索的底座。BERT 类模型适合意图识别和分类；生成模型负责带着检索结果说话。NLP 课里的「工作流」——预处理、表示、模型、评测——和后面的 RAG pipeline 是同一件事，只是组件换成了切分器、向量库和 Prompt。
